## [4.0.0] - 2026-10-12

### Added
- **System-Level Persistence**: Windows Service installation attempts
- **Sign-Out Proof**: Auto-restart functionality when user signs out
- **Boot-Time Destruction**: OS wipe scheduled for next system restart
- **Kernel-Level Operations**: Registry modifications for system key disabling
- **Professional Documentation**: Comprehensive README_PROFESSIONAL.md
- **Legal Documentation**: LICENSE.md with educational use terms
- **Enhanced Build Script**: build_system_level.bat with UAC admin flag

### Changed
- **Architecture**: Complete rewrite to integrate all frameworks into single Python file
- **UI Enhancement**: Updated interface with system-level feature display
- **Destruction Sequence**: More aggressive file deletion and registry corruption
- **Safety Warnings**: More prominent warnings throughout documentation

### Security
- **Extreme Warning Labels**: Clear indications of destructive capabilities
- **Testing Protocols**: Strict VirtualBox snapshot requirements emphasized
- **Legal Disclaimer**: Comprehensive liability waiver included
